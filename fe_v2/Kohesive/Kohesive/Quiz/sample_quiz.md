## What is the output of `print(type([]))`?

- [ ] `<class 'tuple'>`
- [x] `<class 'list'>`
- [ ] `<class 'dict'>`
- [ ] `<class 'set'>`

> Square brackets create a list in Python. The type() function returns the class of the object.

## Which keyword is used to define a function in Python?

- [ ] func
- [x] def
- [ ] function
- [ ] define

> Python uses the `def` keyword to declare functions, followed by the function name and parentheses.

## What does `len("hello")` return?

- [ ] 4
- [x] 5
- [ ] 6
- [ ] Error

> The len() function returns the number of characters in a string. "hello" has 5 characters.

## Which of these is a mutable data type?

- [ ] tuple
- [ ] string
- [x] list
- [ ] frozenset

> Lists are mutable — you can add, remove, and change elements after creation. Tuples, strings, and frozensets are immutable.

## What is the correct way to start a comment in Python?

- [x] # This is a comment
- [ ] // This is a comment
- [ ] /* This is a comment */
- [ ] -- This is a comment

> Python uses the hash symbol (#) for single-line comments. The other syntaxes belong to other languages.
